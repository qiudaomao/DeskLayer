DeskLayer 1.0.0

First release. JavaScript plugins rendered onto the desktop wallpaper, into floating windows, or as macOS widgets, managed from a three-pane manager.

  • Plugins install from a store — an Official and a Sample store are offered in the ＋ menu, and any JSON catalog URL works.
  • Canvas, declarative SwiftUI, and webview render modes.
  • Host APIs for plugins: system stats, shell, AppleScript, SSH, and a local HTTP hook server.
  • English, 简体中文, and 日本語.
